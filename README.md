# Lip.Pick — 립 컬러 탐색 페이지

CJ 사내벤처 니더스팀 개발자 채용 사전 과제로 구현한 모바일 웹 기준 립 컬러 탐색 페이지입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 구현 내용

**필수**

- 제품 카드 목록 — 이미지, 컬러 스와치(hex), 브랜드명, 제품명, 컬러명, 제형 배지, 가격
- 제형 필터 — 전체 / 매트 / 글로시 / 벨벳
- 모바일(390px) 기준 레이아웃, 데스크톱에서는 중앙 정렬(max-width 430px)

**선택**

- 브랜드·제품명·컬러명 텍스트 검색
- 카드 탭 시 바텀시트 상세 화면 (ESC·오버레이 탭으로 닫기)
- 검색/필터 결과 없음 상태 처리

## 기술 스택

- React 19 + Vite
- 순수 CSS (CSS 변수 기반 디자인 토큰)
- Pretendard 웹폰트

## 가장 신경 쓴 부분

1. 주 사용자(18~25세 여성)가 쓰고 싶어지는 화면을 목표로, 웜 크림 배경과 로즈 포인트 컬러, 둥근 카드 형태로 코스메틱 커머스 특유의 부드러운 톤을 만들었습니다.
2. 서비스의 핵심이 "실발색 확인"인 만큼 컬러 스와치를 카드와 상세 화면 모두에서 가장 먼저 눈에 들어오는 요소로 배치했습니다.
3. 1시간 범위 안에서 외부 UI 라이브러리 없이 필수 + 선택 기능과 빈 상태·접근성(키보드 조작, aria)까지 완성도의 균형을 잡았습니다.
