# Lip.Pick — 립 컬러 탐색 페이지

CJ 사내벤처 니더스팀 개발자 채용 사전 과제로 구현한 모바일 웹 기준 립 컬러 탐색 페이지입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 구현 내용

**필수**

- 제품 카드 목록 — 이미지, 컬러 스와치(hex), 브랜드명, 제품명, 컬러명, 제형 배지, 가격
- 제형 필터 — 전체 / 매트 / 글로시 / 벨벳
- 모바일(390px) 기준 레이아웃, 데스크톱에서는 중앙 정렬(max-width 430px)

**선택**

- 브랜드·컬러명 텍스트 검색
- 카드 탭 시 바텀시트 상세 화면 (ESC·오버레이 탭으로 닫기)
- 검색/필터 결과 없음 상태 처리

## 기술 스택

- React 19 + Vite
- 순수 CSS (CSS 변수 기반 디자인 토큰)
- Pretendard 웹폰트

## 가장 신경 쓴 부분

1. 본 서비스의 주 사용자인 18~25세 여성을 타깃으로 디자인 방향을 잡았습니다. 이 타깃이 익숙하게 쓰는 코스메틱 커머스의 톤을 참고해 깔끔한 화이트 베이스에 로즈 포인트 컬러, 둥근 카드와 부드러운 그림자로 "쓰고 싶어지는" 첫인상을 만드는 데 집중했습니다.
2. 서비스의 핵심이 "실발색 확인"인 만큼 컬러 스와치를 카드와 상세 화면 모두에서 가장 먼저 눈에 들어오는 요소로 배치하고, 컬러명 텍스트도 각 제품의 실제 hex 색으로 입혀 목록에서 색이 바로 전달되게 했습니다.
